# Security & Threat Model — VayuMitra

VayuMitra processes live Open-Meteo environmental telemetry, household sensitivity profiles, user questions, and optional user-uploaded room/sky photos. This document summarizes the application's threat model and defense-in-depth controls.

## 1. Threat Model & Implemented Controls

| Asset / Surface | Threat | Control Implemented |
| :--- | :--- | :--- |
| **`GEMINI_API_KEY`** | Key leakage to client bundle, logs, or missing config silent degradation | Strictly server-side (`process.env.GEMINI_API_KEY` via `requireGeminiApiKey()` in `server.ts`). Startup fails fast with `ConfigError` when missing or still set to `'MY_GEMINI_API_KEY'`. Never prefixed with `VITE_`; `.env*` ignored in `.gitignore`; `.env.example` stores placeholders only. |
| **User Photos (`/api/photo-check`)** | GPS/EXIF metadata leakage, MIME spoofing, oversized uploads, photo retention | Client validates MIME (`image/jpeg`, `image/png`, `image/webp`) and `<= 4 MB`, redraws onto an offscreen `<canvas>` (`src/lib/vision/exifStrip.ts`) to strip all EXIF/GPS/XMP headers locally, and revokes blob URLs on unmount/reset. Server re-validates `.strict()` Zod schema, base64 charset, `<= 4 MB` decoded size, and **actual binary magic bytes** (`FF D8 FF` JPEG, `89 50 4E 47` PNG, `RIFF....WEBP` WebP) under a route-scoped `6mb` limit, never stores or caches photos, and never logs image payloads. |
| **API Inputs (`/api/*`)** | Type confusion, coordinate spoofing, oversized payloads, unknown fields | Every POST route enforces `.strict()` Zod schemas (`AdviceRequestSchema`, `AskRequestSchema`, `PhotoCheckRequestSchema`), India geographic bounds (`latitude 6..37.6`, `longitude 68..97.5`), `cityName` regex (`1..80` chars), `question` (`2..300` chars), strict enums, `<`/`>`/control-character sanitization (`sanitizeUserText`), and `64kb` JSON parser limit on text routes. |
| **Prompt Injection & XSS** | Untrusted `cityName`, `question`, or `sceneContext` overriding system rules or injecting HTML | All untrusted user inputs are wrapped in `<untrusted_input name="...">...</untrusted_input>` delimiters with explicit system-instruction overrides to treat tagged content strictly as data. Gemini outputs are constrained by `responseSchema`, validated server-side with Zod, and rendered exclusively via escaped React JSX text nodes (`dangerouslySetInnerHTML` is never used). |
| **CORS & Browser Surface** | Cross-origin abuse, XSS, clickjacking, MIME sniffing, sensor misuse | Origin-locked CORS on `/api/*` rejects foreign origins with HTTP `403`. Every response sets per-request cryptographic nonce CSP (`default-src 'self'`, `script-src 'self' 'nonce-...'`, `style-src 'self' 'nonce-...' https://fonts.googleapis.com`, `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`, `frame-ancestors 'none'`, zero `'unsafe-inline'`, zero `'unsafe-eval'`), `Strict-Transport-Security`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, and `Permissions-Policy: camera=(self), microphone=(), geolocation=()`. `x-powered-by` is disabled. |
| **Abuse, Hang & Quota Exhaustion** | Automated flooding, slow upstream hangs | Per-IP sliding-window rate limits (`20/min` advice, `12/min` ask, `6/min` photo-check) returning HTTP `429` + `Retry-After`, bounded 10-minute caches (`APP_CONFIG.cacheTtlMs`), concurrent in-flight deduplication, `AbortController` upstream/client timeouts, and deterministic bilingual fallbacks. |
| **Operational Logging & Errors** | Secret/PII/prompt leakage in logs or stack traces in API errors | `logStructured` outputs JSON logs and automatically redacts keys matching `/key\|token\|secret\|password\|auth\|imagebase64\|prompt\|question/i`. Central error middleware assigns a `correlationId` and never exposes stack traces or internal errors to clients. |
| **Supply Chain** | Vulnerable npm packages or drifting transitive versions | Exact dependency versions pinned in `package.json`, lockfile verified in `package-lock.json`, `npm audit --omit=dev` and `npm audit` pass with **0 vulnerabilities**. |
